This theme disables the default statusbar in the  WPS screen.
To enable the statusbar, goto the 
"General Settings"->"Display"->"Status-/Scrollbar"-> "Status Bar" setting of your device.

This theme is available for LCD sizes/color bits:
320x240x24  -- iPod 5G Video
             

Information:
------------
This theme is intented to be used while driving.

Uses big fonts and big album art, for a easy view from a distance.
